# Радар — поиск общественных бань

Еженедельный **локальный** прогон агентов (решение владельца 16.10: не на сервере и без ключей API) находит бани в
справочниках и картах, оценивает «индекс общественности» 0–100 и складывает места в таблицу `radar_places`. На сайте
это вкладка «Бани» → «Радар», видна только Комиссии. На карту лиги место попадает только её решением:

- **«В лигу»** — `radar_decide(id, 'add')`: новая баня `type = public`, точка точная; страну и регион по точке дольёт
  ночной разбор `ebl-fill-places` (через несколько минут);
- **«Это наша»** — у места совпало название с баней лиги (`league_hint`), а наша точка неточная или далеко: сайт
  переносит точку через `bath-location` и помечает место `matched`;
- **«Скрыть»** — не баня, аренда, дубль; **«вернуть»** — снова в новые.

## Прогон (раз в неделю, Москва и область, дальше — регионами)

1. **Кандидаты.** OpenStreetMap через Overpass (зеркало `maps.mail.ru/osm/tools/overpass` — `overpass-api.de` часто
   отвечает 500/406): `amenity=public_bath`, `leisure=sauna`, названия «баня/бани/сауна/терм». Плюс справочники глазами:
   2ГИС, фильтр «Парная: Общественная» (капча после ~3 страниц — дальше не идём), Яндекс Карты.
   Мусор (остановки, ручьи «Банька», магазины, терминалы) — правилами по тегам и названию.
2. **Сопоставление с лигой.** По расстоянию и названию; тёзка дальше 1,5 км — только подсказка `league_hint`
   (у части бань лиги точка — заглушка). Хуитнес и термы лиги с общественной не склеиваем.
3. **Разбор агентами** — правила в `scripts/radar/rubric.md`. Пачки по ~20 мест, вслепую (агент не знает тип лиги).
   **Лимит — 200 веб-поисков за ход на всех агентов**: по одному на место и только по справочникам
   (`allowed_domains`: yandex.ru, 2gis.ru, zoon.ru, yell.ru) — обычный поиск по «Баня, Шатура» даёт мусор из других
   регионов. Обходить лимит поисковиками через загрузку страниц нельзя; капчи не обходим.
4. **Заливка.** `python3 scripts/radar/push.py radar.json > /tmp/radar.sql` и `supabase db query --linked -f /tmp/radar.sql`
   (на бой — с согласия владельца). Ключ места стабилен между прогонами; решения Комиссии заливка не затирает,
   `first_seen` показывает новые.

## Точность (16.10, Москва)

Проверка вслепую на 70 банях лиги с типом от Комиссии: при пороге 70 точность 92%, полнота 85%. Ложные «общественные» —
номерные отделения тех же зданий, где есть общее; пропуски — где агент держался старого правила «обязательно раздельно
по полу» (Гремм, «Не парься»). Тип в лиге — у отделения («Варшавские, мужской» — общественная, «высший» — частная),
радар отвечает за заведение: есть ли общее отделение.

Храним только своё: название, адрес, точку, вывод, короткие цитаты с сайтов бань и ссылки. Отзывы, фото и рейтинги
справочников к себе не копируем.

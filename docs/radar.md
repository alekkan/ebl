# Радар — поиск общественных бань

Еженедельный **локальный** прогон агентов (решение владельца 16.10: не на сервере и без ключей API) находит бани в
справочниках и картах, оценивает «индекс общественности» 0–100 и складывает места в таблицу `radar_places`. На сайте
это вкладка «Бани» → «Радар», видна только Комиссии. На карту лиги место попадает только её решением.

**Как устроена страница** (16.10, `prototype/app.js`, раздел «Радар»). Вкладки — по смыслу решения, со счётчиками:
«Новые» (общественные, индекс ≥ 70, в лиге нет), «Наши» (совпало название с баней лиги — `league_hint`), «Спорные»
(билет есть, но на грани хуитнеса или данных мало), «Без данных», «Прочее» (аренда, спа, закрытые), «Решено».
Группу считает `radarBase()` на сайте, пороги — там же. Список слева, карта справа (на телефоне — сверху, сворачивается);
на карте — точки текущей вкладки, наведение на карточку подсвечивает точку, клик по точке — к карточке. Сверху —
«Разобрано X из Y» по новым, нашим и спорным. В карточке: вердикт словами и индекс, факты (мужские и женские дни, билет
на человека, цена), заметка агента, ссылки на сайт, Яндекс Карты и 2ГИС, «Подробнее» — цены, цитаты с сайтов, когда и где нашли.

Решения — `radar_decide(id, action, bath, type, reason)`, подтверждение — строкой на месте кнопок, без диалогов:

- **«Завести в лигу»** — `add`: новая баня с выбранным типом (`public` / `spa` / `private`; по умолчанию — из `kind`),
  точка точная; страну и регион по точке дольёт `ebl-fill-places` (через несколько минут). Второе нажатие — та же баня.
- **«Перенести точку „X“ сюда»** — во вкладке «Наши»: сайт переносит точку бани лиги через `bath-location`, место — `matched`.
  Клик по названию рисует на карте нашу точку сейчас и пунктир до найденного места. Если это другая баня — «Это другая — завести».
- **«Скрыть»** — `hide` с причиной одним нажатием (`hide_reason`: `not_bath`, `rental`, `spa`, `closed`, `duplicate`,
  `other`) — она же метка для следующего прогона. Внизу всплывает «Отменить».
- **«Вернуть»** — `reopen`, только у скрытых. Заведённую баню правят в её карточке на карте: «Вернуть» оставил бы её
  в лиге, и второе «Завести» дало бы дубль.

## Прогон раз в неделю — по шагам

Всё лежит в `scripts/radar/`, папка прогона — `scripts/radar/runs/<дата>/` (в git не попадает). Пример — Москва и область.

```bash
R=scripts/radar/runs/$(date +%F); P=scripts/radar/runs/<прошлая дата>/radar.json   # P — итог прошлого прогона
python3 scripts/radar/collect.py "Москва" $R && mv $R/candidates.json $R/candidates_msk.json
python3 scripts/radar/collect.py "Московская область" $R && mv $R/candidates.json $R/candidates_mo.json
python3 scripts/radar/batches.py $R --prev $P --max 190
```

1. **Кандидаты** (`collect.py`): все бани и сауны региона из OpenStreetMap (Overpass, зеркало `maps.mail.ru`, запасной —
   `overpass-api.de`), мусор отсеян правилами (остановки «Баня», ручьи «Банька», магазины, терминалы), то, что уже есть
   в лиге (то же название ближе 1,5 км), — не берём; совпало только название — подсказка `league_hint` («это наша?»).
   Справочники добавляй руками в `$R/directory.txt` строками «название|адрес|рубрика»: 2ГИС, поиск «Общественные бани»
   с фильтром «Парная: Общественная» (после ~3 страниц капча — дальше не идём), Яндекс Карты.
2. **Пачки** (`batches.py`): по ~20 мест, вслепую, сначала похожие на общественные; уже разобранное прошлым прогоном
   (`--prev`, не unknown) пропускается. **Лимит — 200 веб-поисков за ход на всех агентов**, поэтому `--max 190`:
   остальное — следующим ходом тем же скриптом (он учтёт уже готовое в `$R/out`).
3. **Агенты**: на каждую пачку — агент с заданием из `scripts/radar/prompt.md` (подставить `{RUN}` и `{N}`), все разом.
   Поиск — один на место и только по справочникам (`allowed_domains`: yandex.ru, 2gis.ru, zoon.ru, yell.ru): обычный
   поиск по «Баня, Шатура» даёт мусор из других регионов. Поисковики через загрузку страниц — это обход лимита, нельзя;
   капчи и 429 не обходим. Ответы — в `$R/out/batch_N.json`.
4. **Сборка** (`build.py`): `python3 scripts/radar/build.py $R --prev $P` → `$R/radar.json` (ответы поверх прошлого
   итога; не бани выкидываются; цитаты — только с сайтов бань).
5. **Заливка** (с согласия владельца, это данные на бою):
   `python3 scripts/radar/push.py $R/radar.json > /tmp/radar.sql && supabase db query --linked -f /tmp/radar.sql`.
   Ключ места одинаков между прогонами; решения Комиссии заливка не трогает, `first_seen` показывает новые места.
6. **Комиссии** — «в Радаре N новых»: вкладка «Бани» → «Радар».

Проверить правила разбора можно на банях лиги с известным типом: их же прогнать через `batches.py` вслепую и сравнить
ответы с типами Комиссии (так считали точность ниже).

## Точность (16.10, Москва)

Проверка вслепую на 70 банях лиги с типом от Комиссии: при пороге 70 точность 92%, полнота 85%. Ложные «общественные» —
номерные отделения тех же зданий, где есть общее; пропуски — где агент держался старого правила «обязательно раздельно
по полу» (Гремм, «Не парься»). Тип в лиге — у отделения («Варшавские, мужской» — общественная, «высший» — частная),
радар отвечает за заведение: есть ли общее отделение.

Храним только своё: название, адрес, точку, вывод, короткие цитаты с сайтов бань и ссылки. Отзывы, фото и рейтинги
справочников к себе не копируем.

# Единый каталог — точки и факты по баням лиги

Зачем (19.10, решение владельца): у 830 из 1170 бань лиги точка примерная (центр города, региона, страны), а у 109 —
«среднеточная» (геокодер нашёл по названию 26.09, никто не проверял). Для карты, бонусов за регион и каталога Парсовета
нужна точная точка у каждой бани. Заодно собираем факты для портала: адрес, ссылки, часы, мужские и женские дни, цену,
отделения, что есть в бане.

Первый прогон — **все общественные** (461), включая точные: агенты проверяют и их. Регион и страну Комиссия указывала
почти всегда верно — это опора поиска; если найденное место в другом регионе, баня идёт в отдельный список, регион
не меняем. Как Комиссия обрабатывает найденное — решаем по итогам прогона.

## Шаги

Всё — в `scripts/catalog/`, папка прогона — `scripts/catalog/runs/<дата>/` (в git не попадает).

```bash
python3 scripts/catalog/export.py scripts/catalog/runs/2026-10-19     # общественные бани с боя (только чтение) → input.json
python3 scripts/catalog/osm.py scripts/catalog/runs/2026-10-19        # кандидаты из OpenStreetMap (Photon) → osm.json, ~30 мин
python3 scripts/catalog/batches.py scripts/catalog/runs/2026-10-19    # пачки по 8 бань на ход (до 95 бань: ≤2 веб-поиска на баню)
# агенты по scripts/catalog/prompt.md — по одному на пачку, параллельно; ответы → out/batch_N.json
python3 scripts/catalog/build.py scripts/catalog/runs/2026-10-19      # catalog.json и report.md
python3 scripts/catalog/push.py scripts/catalog/runs/2026-10-19 > /tmp/catalog.sql   # на бой — с согласия владельца:
supabase db query --linked -f /tmp/catalog.sql                        # предложения → вкладка «Сверка» у Комиссии
```

`batches.py` пропускает уже разобранное — следующим ходом запусти его снова. Порядок: сначала бани с походами в 2026,
потом по числу походов; отделения одного здания («1р», «2вр», «высший», «мужской») — подряд, в одной пачке.

## Что собирает агент

Точка (с карточки 2ГИС или Яндекс Карт, или кандидат OSM, если сходится адрес), адрес, город, регион по карточке,
сайт, ссылки на Яндекс Карты и 2ГИС, телефон, статус (работает / закрыта / ремонт), общественная ли, часы, мужские и
женские дни, цена с датой и источником, отделения, что есть (дровяная печь, купель, веники, парильщик, кафе), цитаты
с сайта бани.

**Индекс уверенности** (0–100) — насколько найденное место та самая баня лиги: 90+ — название, город и регион сошлись
и адрес подтверждён двумя источниками; 70–89 — название и город, источник один; 40–69 — сомнения; ниже — не нашли.
`build.py` добавляет +5, если точка сошлась с OpenStreetMap, и +5, если рядом с нашей точной/среднеточной.

## Вкладка «Сверка» у Комиссии (19.10)

«Бани» → «Сверка» (`#catalog`), как Радар: вкладки по смыслу решения, список слева, карта справа. В карточке две строки:
**«У нас»** — как баня записана в лиге (тип, регион и страна, точность точки, походы, кто был) и **«Нашли»** — название и
адрес по карточке, откуда точка и как далеко от нашей, расхождение региона, часы, мужские и женские дни, цена, заметка
агента; ссылки на сайт, Яндекс Карты и 2ГИС; «Подробнее» — почему уверены, телефон, отделения, цитаты с сайта.

Вкладки (`catBase()` в `prototype/app.js`): **«Уверенные»** — индекс ≥ 90, точка есть, наша не «точная далеко»: можно
«Принять все» пачкой (со строкой подтверждения); **«Проверить»** — 70–89 или наша точная/среднеточная далеко; **«Регион»**
— регион по карточке не тот; **«Флажки»** — закрыта, ремонт, не общественная; **«Не нашли»** — ниже 70; **«Решено»**.

Решения — `catalog_decide(ids, action, reason)`, таблица `catalog_proposals` (миграция `20261019140000`):
- **«Принять»** (`accept`) — найденная точка становится точной; нашу точную ближе 300 м не двигаем (её ставил человек).
  Без координат — просто «Подтвердить данные». Регион не меняется никогда.
- **«Оставить нашу точку»** (`keep`) — данные принимаем, точку не трогаем.
- **«Отклонить»** (`reject`) — причина одним нажатием: другая баня, точка не та, не общественная, закрыта, дубль, другое.
- **«Вернуть»** / «Отменить» (`reopen`) — принятая точка возвращается прежней, если баню с тех пор не двигали.

Повторная заливка того же прогона обновляет данные, решения Комиссии не трогает. Факты (цены, дни, сайты) пока только
в сверке; показывать их в карточке бани и в Парсовете — следующим шагом, после решений Комиссии.

## Правила (как в Радаре)

- Поиск — только `WebSearch` с `allowed_domains` (yandex.ru, 2gis.ru, zoon.ru, yell.ru), не больше двух на баню,
  лимит 200 за ход на всех агентов. Лимит не обходим поисковиками через `WebFetch`; капчи и 429 не обходим.
- Отзывы — только как источник фактов, своими словами. Тексты отзывов, рейтинги и фото не копируем. Цитаты — только
  с сайта самой бани, до 20 слов.
- Регион не исправляем — конфликт идёт Комиссии отдельно.
- На бой ничего не пишем: результат — файлы прогона; что и как применять — решение владельца и Комиссии.

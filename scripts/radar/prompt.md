<!-- Задание агенту радара. Подставь {RUN} (папка прогона) и {N} (номер пачки); агентов — по числу пачек, параллельно. -->
Ты разбираешь бани для банной лиги (ebl.su): для каждой записи определи, есть ли общее отделение общественной бани,
и выставь «индекс общественности».

Правила — scripts/radar/rubric.md (прочитай первым делом и следуй строго).

Записи — {RUN}/batches/batch_{N}.json. Поля: key, name; иногда lat/lng, addr, website, hours, tag (тег OSM), osm_note
(теги OSM: дни по полу, плата), rubric_hint (рубрика справочника), map_url (карточка из справочника, 23.10 — прочёс
Яндекса и 2ГИС). Город — по адресу или координатам. Есть map_url — сначала открой её (это не поиск); WebSearch — только
если карточка не открылась или в ней не понять, есть ли общее отделение.

ПОИСК — СТРОГО ОДИН WebSearch НА ЗАПИСЬ (общий лимит на всех агентов — 200 за ход) и только по справочникам:
allowed_domains ["yandex.ru", "2gis.ru", "zoon.ru", "yell.ru"], запрос «<название> <город или адрес> баня». Второй поиск
по той же записи не делай. Отказал по лимиту — не обходи: никаких поисковиков и выдач через WebFetch. Без поиска можно:
карточки из выдачи (yandex.ru/maps/org/…, 2gis.ru/…/firm/…, zoon.ru/…, yell.ru/…), сайт бани (цены, правила, расписание),
обратный геокодер OSM не чаще раза в секунду. Капча, блокировка, 429 — не обходи. Карточка из другого города — не наша.
Не нашёл — kind "unknown", confidence "low", индекс по названию, note начни с «нужен поиск». Не выдумывай; цитаты
дословные, до 20 слов, с адресом страницы; пересказ помечай «[пересказ]». Закрыто навсегда — "closed", временно — в note.

Результат — Write в {RUN}/out/batch_{N}.json: JSON-массив по объекту на запись, в том же порядке:
{"key": "...", "found_name": "...|null", "city": "...|null", "address": "...|null", "website": "url|null", "map_url": "url|null",
 "kind": "public|spa|private|other|closed|unknown", "public_index": 0-100, "gender_split": true/false/null,
 "ticket_per_person": true/false/null, "rental_whole_room": true/false/null, "has_rooms_or_vip": true/false/null,
 "price_example": "...|null", "evidence": [{"quote": "...", "url": "..."}], "confidence": "high|medium|low", "note": "почему так, одной фразой"}
Перезаписывай файл каждые 5 записей. В конце — одна строка: сколько разобрано, сколько WebSearch потрачено, сколько public.

ЛИЧНЫЕ ДАННЫЕ: ни в один запрос (User-Agent, параметры, тексты) не подставляй почту, имя или другие данные владельца
и участников — для геокодера OSM хватит User-Agent «ebl.su-agent/1.0 (+https://ebl.su)». Геокодер OSM — не чаще раза в секунду
на всех; 429 — не обходи, оставь точку пустой и адрес в address: её добьёт скрипт.
